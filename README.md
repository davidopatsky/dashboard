# Dashboard

Jednostránková aplikace (GitHub Pages). V repozitáři je jen kód — žádná data.
Data si stránka při otevření stahuje ze zdroje nastaveného v `config.js`.

- `index.html` — stránka a vzhled
- `app.js` — načtení dat a vykreslení dashboardu „Pro vedení"
- `config.js` — adresa zdroje dat

Lokální náhled s vlastním souborem dat: `index.html?api=cesta/k/datum.json`
